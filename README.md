# Budget Planner per Android

Qui ci sono solo le versioni dell'app per il telefono, pronte da installare. Il codice sta nel repository dell'app.

## Installare o aggiornare
1. Apri l'ultima versione da **[Releases](https://github.com/Davide-Vicenzi/budget-planner-android-releases/releases/latest)** e scarica il file `Budget-Planner-X.Y.Z.apk`.
2. Aprilo dal telefono. La prima volta Android chiede di consentire l'installazione da quella fonte.
3. Se Play Protect avvisa che l'app è sconosciuta, scegli «Installa comunque».

Le versioni nuove si installano sopra la precedente e i dati restano. Dall'app, in Altro › Impostazioni › Aggiornamenti, si controlla se c'è una versione nuova e si installa con un tocco.
